# ShopHub 前端项目 - 快速开始指南

## 项目启动

```bash
# 1. 进入项目目录
cd d:\Programming\Vue\Shopping\frontend

# 2. 启动开发服务
pnpm dev

# 浏览器自动打开 http://localhost:3000
```

## 功能演示流程

### 1. 浏览商品（首页）
- 访问 `http://localhost:3000`
- 查看商品列表（每页 12 件）
- 点击分类过滤商品
- 使用搜索框查找商品
- 点击"详情"查看商品详情页

### 2. 商品详情
- 从首页点击商品的"详情"按钮
- 或直接访问 `http://localhost:3000/product/{id}`
- 查看商品图片、价格、评分
- 选择数量，点击"加入购物车"
- 点击❤️ 收藏商品

### 3. 购物车和结账流程
```
1. 点击顶部购物车图标 → /checkout/cart
   - 查看购物车中的商品
   - 调整数量或删除商品
   - 点击"前往结账"

2. 订单确认 → /checkout/checkout
   - 填写收货地址
   - 选择配送方式（标准/快递）
   - 选择支付方式（卡/转账/钱包）
   - 点击"下一步"

3. 支付选择 → /checkout/payment
   - 确认支付方式
   - 查看订单汇总
   - 点击"提交订单"

4. 订单成功 → /checkout/order-confirmation
   - 查看订单号和详情
   - 点击"查看我的订单"进入订单历史
   - 或点击"继续购物"返回首页
```

### 4. 用户账户系统
#### 注册新账户
```
1. 点击顶部"账户" → 点击"注册"
2. 或直接访问 http://localhost:3000/auth/register
3. 填写：用户名、邮箱、密码、确认密码
4. 同意服务条款，点击"创建账户"
5. 自动登录并返回首页
```

#### 登录（演示账户）
```
邮箱: demo@example.com
密码: 123456

登录步骤：
1. 点击顶部"账户" → 点击"登录"
2. 或直接访问 http://localhost:3000/auth/login
3. 输入邮箱和密码
4. 点击"登录"
5. 成功登录后返回首页
```

### 5. 个人中心
#### 个人资料页
```
http://localhost:3000/user/profile

功能：
- 查看账户名和邮箱
- 点击"编辑资料"修改名称和邮箱
- 查看收货地址（演示地址）
- 查看我的收藏商品
```

#### 订单历史页
```
http://localhost:3000/user/orders

功能：
- 查看所有已下订单
- 按订单状态过滤（全部/待发货/已发货/已收货）
- 查看订单详情和金额
- 点击"再次购买"快速重新购买
```

### 6. 用户菜单
点击顶部"账户"按钮，可以看到下拉菜单：
- **未登录**：登录 / 注册
- **已登录**：我的账户 / 订单历史 / 退出登录

## 主要页面路由

| 路由 | 页面 | 说明 |
|------|------|------|
| `/` | 首页 | 商品列表、搜索、分类、排序 |
| `/product/[id]` | 商品详情 | 商品详细信息、评价、购买 |
| `/checkout/cart` | 购物车 | 查看和管理购物车 |
| `/checkout/checkout` | 订单确认 | 地址、配送、支付选择 |
| `/checkout/payment` | 支付选择 | 支付方式确认 |
| `/checkout/order-confirmation` | 订单成功 | 订单成功提示和查看订单 |
| `/auth/login` | 登录 | 用户登录 |
| `/auth/register` | 注册 | 新用户注册 |
| `/user/profile` | 个人资料 | 查看和编辑个人信息 |
| `/user/orders` | 订单历史 | 查看所有订单 |

## 关键功能说明

### 搜索功能
1. 在 Header 的搜索框输入商品名称
2. 按 Enter 或点击搜索按钮
3. 自动跳转到首页并过滤搜索结果
4. 清除搜索词返回全部商品

### 分类过滤
1. 在首页轮播下方点击分类
2. 自动过滤该分类的商品
3. 侧边栏会高亮显示选中分类
4. 点击侧边栏"全部分类"或"重置过滤"清除分类

### 分页导航
1. 商品列表下方显示分页控件
2. 点击页码直接跳转
3. 使用"上一页"和"下一页"按钮
4. 最多显示 5 个页码

### 收藏功能
1. 在商品卡片或详情页点击❤️ 按钮
2. 商品添加到收藏
3. 进入个人中心 > 我的收藏 查看
4. 再次点击❤️ 取消收藏

### 本地存储
- 购物车数据自动保存到浏览器
- 收藏列表自动保存
- 用户登录信息自动保存
- 订单历史自动保存
- 页面刷新不会丢失数据

## 浏览器开发者工具

### 查看本地存储
1. 按 F12 打开开发者工具
2. 选择"应用"标签
3. 左侧"存储" → "Local Storage" → "http://localhost:3000"
4. 可以看到以下键值：
   - `cart` - 购物车数据
   - `favorites` - 收藏列表

   - `orders` - 订单历史

## 常见问题

### Q: 页面显示为空白？
A: 
1. 检查浏览器控制台是否有错误
2. 确保在项目根目录运行 `pnpm dev`
3. 尝试清除浏览器缓存或使用隐身模式

### Q: 登录不了？
A:
1. 使用演示账户：demo@example.com / 123456
2. 或创建新账户

### Q: 购物车数据丢失？
A:
1. 检查浏览器是否禁用了 localStorage
2. 在隐身模式下 localStorage 是临时的
3. 清除浏览器数据会删除所有本地存储

### Q: 图片无法加载？
A:
1. 项目使用 Unsplash 动态生成的图片 URL
2. 需要网络连接
3. 生产环境应替换为本地或 CDN 图片
